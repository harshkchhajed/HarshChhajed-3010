## 🚀 Projects

- **[ARBot – Teleoperation & Replay](https://cake.wpi.edu/arbot-website/)**
  <p align="justify">A ROS 2 real-time teleoperation-and-replay framework driving a 6-DoF PiPER arm (position-based QP + damped-least-squares IK), reaching 5.0 mm median tracking accuracy at 19.5 ms latency, with a released 132-trajectory dataset. Published at ACM MMSys 2026.</p>
- **[RoboFusion – Manipulator Teleoperation](https://github.com/harshkchhajed/RoboFusion)**
  <p align="justify">An IMU + vision sensor-fusion stack teleoperating a 4-DOF OpenManipulator-X arm from human wrist motion, raising gesture-recognition accuracy from 80% to 95%.</p>
- **[Chance-Constrained RRT Motion Planning](https://github.com/harshkchhajed/MotionPlanningProjects/tree/main/FinalProject/code)**
  <p align="justify">Robust sampling-based motion planning under uncertainty, integrated with OMPL in C++, improving success rate by 20% and cutting planning time by 33% versus RRT and RRT*.</p>
- **Semi-Autonomous Agricultural Robot**
  <p align="justify">A 4x4 field robot for real-time crop-disease detection using YOLO + custom CNN classifiers, reaching 90% precision across 20+ hours of field trials, with an IoT dashboard cutting manual monitoring by 30%.</p>
- **Biometric Attendance System**
  <p align="justify">A cost-effective IoT fingerprint attendance solution on ESP32 + Firebase with cloud storage and custom 3D-printed enclosures, eliminating manual paperwork for 25 users.</p>
